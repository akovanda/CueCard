
1. Get the service URL by running these commands:
  kubectl port-forward svc/{{ include "cuecard.fullname" . }} 8000:{{ .Values.service.port }}

2. Test:
  curl -s http://localhost:8000/health

3. Authenticated request example:
  curl -s http://localhost:8000/config -H "{{ .Values.security.apiKeyHeaderName }}: <your cuecard api key>"
