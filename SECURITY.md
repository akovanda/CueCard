# Security Policy

## Supported versions
The latest release and `main` branch receive security updates on a best-effort basis.

## Reporting a vulnerability
We use GitHub Security Advisories. To report a vulnerability:

1. Go to the repository page on GitHub.
2. Click on "Security" -> "Advisories" -> "Report a vulnerability".
3. Provide details (affected versions, impact, and steps to reproduce). Attach PoC if possible.

Please do not open public issues for sensitive reports. We aim to acknowledge within 3–5 business days.

## Disclosure
We follow responsible disclosure. Once a fix is available, we will publish an advisory and credit reporters (if desired) in the release notes.
